# Smart Heritage Guide Automation Workflow using UiPath

## Project Overview

This project automates heritage tourism workflows using UiPath. The system processes visitor information, generates visitor IDs, and stores tourism records automatically using Excel automation and workflow automation concepts.

## Features

* Visitor information automation
* Heritage tourism workflow management
* Excel data processing
* Automated reporting system
* Visitor ID generation
* Workflow automation using UiPath

## Technologies Used

* UiPath Studio
* Excel Automation
* Robotic Process Automation (RPA)
* Workflow Automation
* DataTables

## Workflow

1. Read visitor data from Excel
2. Generate Visitor IDs
3. Process tourism workflow
4. Store automated reports
5. Manage heritage visitor records

## Output

The automation generates:

* Visitor ID
* Visitor Name
* Place
* Category
* Status
* Date

inside `HeritageReport.xlsx`.
